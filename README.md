#  Sistema de Información - Dulce Belleza

Este proyecto está siendo desarrollado como caso de estudio práctico dentro del programa tecnológico **Análisis y Desarrollo de Software (ADSO)** en el SENA. Consiste en una solución tecnológica para optimizar la gestión de inventario, el registro de clientes y el control de ventas de la tienda de ropa femenina *Dulce Belleza*.

##  Estado del Proyecto: Fase de Análisis
Actualmente el equipo se encuentra en la fase inicial de levantamiento de requerimientos, especificación de casos de uso y diseño de interfaces (Storyboards).

## Estructura del Repositorio
- `/fase-analisis`: 
  - `/documentacion`: Casos de estudio, cuestionario y resultados de la entrevista de levantamiento de información, y especificación de requisitos.
- `/database` *(Próximamente)*: Modelos de datos y arquitectura de base de datos relacional.
- `/backend` *(Próximamente)*: Lógica de negocio y desarrollo del sistema.

## Tecnologías en Evaluación
- **Lenguajes y Tecnologías:** Evaluación de alternativas para el desarrollo (Python, JavaScript, Java, HTML/CSS).
- **Base de Datos:** Relacional (SQL).
- **Entorno de Desarrollo:** Visual Studio Code.
- **Control de Versiones:** Git & GitHub.
